# Sicherheitsrichtlinie

Bitte melde vermutete Sicherheitslücken nicht als öffentliches Issue.

Nutze, sofern für dieses Repository verfügbar, GitHubs Funktion **Report a vulnerability** unter dem Reiter **Security**. Falls sie nicht verfügbar ist, kontaktiere den Repository-Inhaber über dessen GitHub-Profil und teile zunächst keine sensiblen technischen Details öffentlich.

Öffentliche Issues mit Geheimnissen, Kundendaten oder ausnutzbaren Details können zum Schutz Betroffener geschlossen oder redigiert werden.
