# Support

Das Issue-Tracking ist für reproduzierbare Fehler und konkrete Funktionswünsche der App CVE-Lagebericht vorgesehen.

Bitte veröffentliche niemals:

- Zugangsdaten oder API-Tokens
- Tenant- oder Kundenkennungen
- vertrauliche CVE-Berichte
- interne Infrastruktur- oder Assetdaten

Allgemeine Fragen können als GitHub Issue gestellt werden, sofern sie keine vertraulichen Inhalte enthalten.
