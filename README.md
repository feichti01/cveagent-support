# CVE Agent Support

Öffentliches Support- und Fehlertracking für die macOS-App **CVE Agent**.

- Supportseite: https://feichti01.github.io/support/cveagent/
- Datenschutzerklärung: https://feichti01.github.io/support/cveagent/privacy.html
- Fehlerbehebung: https://feichti01.github.io/support/cveagent/troubleshooting.html

## Fehler melden

Bitte verwende das strukturierte [Bugformular](https://github.com/feichti01/cveagent-support/issues/new?template=bug_report.yml).

Vor dem Absenden:

- Prüfe, ob der Fehler bereits gemeldet wurde.
- Nenne App-Version, Buildnummer und macOS-Version.
- Beschreibe die notwendigen Schritte zur Reproduktion.
- Entferne Tokens, Zugangsdaten, Tenant-IDs, Kundendaten und vertrauliche Berichtsinhalte.

## Funktionswunsch

Neue Ideen können über das [Feature-Formular](https://github.com/feichti01/cveagent-support/issues/new?template=feature_request.yml) vorgeschlagen werden.

## Sicherheitslücken

Sicherheitslücken und sensible Informationen gehören **nicht** in öffentliche Issues. Beachte [SECURITY.md](SECURITY.md).

Dieses Repository enthält keinen Produktquellcode und keine Zugangsdaten.
